# Phase 2: Content-Tools Setup

## 2.1 CapCut (Video-Editing)

### Mobile App (Haupttool):

**1. Download**
- iOS: App Store → "CapCut"
- Android: Play Store → "CapCut"
- **Größe:** ~300 MB
- **Kosten:** Kostenlos (In-App-Käufe optional)

**2. Account erstellen**
- App öffnen
- "Mit E-Mail anmelden" oder TikTok-Account verbinden (einfacher!)
- **Vorteil TikTok-Login:** Cloud-Sync, Templates

**3. Wichtige Features aktivieren**
- "Auto-Captions" testen (Menü → Text → Auto-Captions)
- "Templates" durchstöbern (Trending nutzen!)
- "Effekte" erkunden

**4. Erste Schritte Tutorial**
- CapCut hat eingebautes Tutorial
- 10 Min durchgehen!
- Oder: YouTube "CapCut Tutorial Deutsch"

**5. Wichtigste Funktionen merken:**
```
✂️ Cut: Videos schneiden (tippe auf Timeline)
📝 Text: Untertitel hinzufügen
🎵 Audio: Musik & Sound-Effekte
⚡ Effects: Übergänge & Effekte
🎨 Filters: Farbkorrektur
⏱️ Speed: Video beschleunigen/verlangsamen
```

**6. Export-Settings (wichtig!):**
- **Auflösung:** 1080p (mindestens!)
- **Frame Rate:** 30fps (oder 60fps)
- **Format:** 9:16 (Vertical für TikTok/Reels/Shorts)

**Desktop-Version (optional):**
- Download: capcut.com
- Gleiche Funktionen, größerer Screen
- Gut für komplexere Edits

**✅ Done: CapCut ready to edit!**

## 2.3 ChatGPT (Ideenfindung & Scripts)

### Schritt-für-Schritt:

**1. Account erstellen**
- Gehe zu: chat.openai.com
- "Sign up"
- E-Mail + Passwort (oder Google/Microsoft-Login)
- Verifiziere E-Mail

**2. Free vs. Plus?**
- **Free (GPT-3.5):** Ausreichend für Start
- **Plus (GPT-4):** €20/Monat - bessere Ergebnisse, Plugins
- **Empfehlung:** Start Free, nach 2 Wochen upgrade

**3. Custom Instructions einstellen** (Game-Changer!)
- Settings → "Custom Instructions"
- **Was möchte ChatGPT über dich wissen?**
```
Ich bin ein deutscher Content Creator im Bereich KI & Tech.
Zielgruppe: 18-35 Jahre, deutschsprachig, interessiert an praktischen KI-Tools.
Plattformen: TikTok, Instagram, YouTube Shorts.
Content-Stil: Kurz, knackig, praktisch, ohne Tech-Jargon.
```
- **Wie soll ChatGPT antworten?**
```
- Auf Deutsch
- Kurze, prägnante Sätze
- Praktische Beispiele
- Keine langen Erklärungen
- Format für Social Media optimiert
```

**4. Wichtige Prompts speichern** (Beispiele):

**Ideen-Generator:**
```
Gib mir 10 virale TikTok-Video-Ideen zum Thema [KI-Tool/Thema].
Format: Hook + Content + CTA, jeweils 30-45 Sekunden.
```

**Script-Writer:**
```
Schreibe ein TikTok-Script (30 Sek) für:
Tool: [Name]
Hook: [Problem/Benefit]
Zielgruppe: Deutsche Tech-Interessierte
Style: Energetisch, praktisch
```

**Hashtag-Generator:**
```
Generiere 10 Hashtags für ein TikTok-Video über [Thema].
Mix: 3 Trending, 5 Nischen, 2 Micro.
```

**5. ChatGPT Mobile App**
- iOS/Android: "ChatGPT" von OpenAI
- Praktisch für unterwegs
- Voice-Input möglich!
