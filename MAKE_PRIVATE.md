# Repository auf Privat setzen

## Anleitung

Um dieses Repository privat zu machen:

1. Gehe zu: https://github.com/hrshojaei/hrshojaei/settings
2. Scrolle ganz nach unten zum "Danger Zone" Bereich
3. Klicke auf "Change visibility"
4. Wähle "Make private"
5. Bestätige die Änderung

## Oder via GitHub CLI

Falls du GitHub CLI installiert hast:

```bash
gh repo edit hrshojaei/hrshojaei --visibility private
```

## Was bedeutet das?

- ✅ Nur du und explizit eingeladene Collaborators können das Repository sehen
- ✅ Der Code ist nicht mehr öffentlich zugänglich
- ✅ Issues, Pull Requests und Commits sind nur für Mitglieder sichtbar
- ✅ Die n8n und Notion Integration funktioniert weiterhin
- ⚠️ GitHub Actions Minutes können bei privaten Repos begrenzt sein (je nach Plan)

## Hinweis

Ich (als Agent) habe keinen direkten Zugriff auf Repository-Einstellungen und kann diese Änderung nicht für dich vornehmen. Du musst dies manuell in den GitHub-Einstellungen durchführen.
